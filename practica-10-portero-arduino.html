1. Introducción

En este proyecto construiremos un portero electrónico utilizando Arduino y un servo motor.

El portero reaccionará cuando se presionen dos botones:

  • Botón izquierdo: el portero se mueve a la izquierda.
  • Botón derecho: el portero se mueve a la derecha.

Este tipo de sistemas se utilizan en robótica para interpretar señales de entrada y controlar movimientos mecánicos.

2. Objetivo

Comprender cómo funcionan las entradas digitales utilizando botones y cómo controlar un servo motor mediante programación con Arduino.

3. Materiales

  • Arduino UNO
  • Protoboard
  • 2 PushButton
  • 2 resistencias de 10kΩ
  • 1 Servo motor
  • Cables jumper
  • Cable USB

4. Funcionamiento del sistema

  1. El Arduino espera que se presione un botón.
  2. Si se presiona el botón izquierdo, el servo gira hacia la izquierda simulando que el portero se lanza a detener el balón.
  3. Si se presiona el botón derecho, el servo gira hacia la derecha.
  4. Cuando ningún botón está presionado, el portero permanece en el centro.

5. Conexión del circuito

Botón 1 (Izquierda)

  • Una terminal del botón va a 5V
  • La otra terminal del botón va al pin digital 3
  • Del mismo punto del pin 3 se conecta una resistencia de 10kΩ a GND

Botón 2 (Derecha)

  • Una terminal del botón va a 5V
  • La otra terminal del botón va al pin digital 2
  • Del mismo punto del pin 2 se conecta una resistencia de 10kΩ a GND

Servo motor

  • Rojo → 5V
  • Negro → GND
  • Amarillo/Naranja → Pin 9

6. Código del proyecto

#include <Servo.h>

Servo portero;

int botonIzq = 3;
int botonDer = 2;

void setup() {
  portero.attach(9);

  pinMode(botonIzq, INPUT);
  pinMode(botonDer, INPUT);
}

void loop() {
  int izq = digitalRead(botonIzq);
  int der = digitalRead(botonDer);

  if (izq == HIGH) {
    portero.write(40);
  }

  if (der == HIGH) {
    portero.write(140);
  }

  if (izq == LOW && der == LOW) {
    portero.write(90);
  }
}

7. Explicación del programa

  • Servo.h permite controlar servomotores.
  • digitalRead() detecta si un botón fue presionado.
  • portero.write() mueve el servo a un ángulo específico.
Ángulo Movimiento
40° Izquierda
90° Centro
140° Derecha

8. Actividad práctica

  1. Armar el circuito en protoboard.
  2. Verificar conexiones.
  3. Cargar el código en Arduino.
  4. Probar el funcionamiento del portero.

9. Reto extra (opcional)

  • Modificar el programa para agregar una tercera posición.
  • Hacer que el portero regrese automáticamente al centro después de 1 segundo.
