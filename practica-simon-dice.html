Primero completa tus respuestas en esta hoja. Cuando termines, usa el botón para abrir la versión de impresión y guardar un PDF con tus propias respuestas.

¿Qué vamos a aprender?

En este proyecto aprenderás a crear un juego de memoria usando una tarjeta Arduino, botones, luces y sonidos.

El reto será recordar una secuencia de colores que el sistema te mostrará y repetirla correctamente.

Aprendizajes esperados

  • Reconocer entradas (botones) y salidas (luces y sonido).
  • Seguir instrucciones paso a paso.
  • Comprender qué es una secuencia.
  • Relacionar acciones físicas con instrucciones digitales.
  • Trabajar en equipo y resolver problemas.

Materiales

  • 1 Arduino UNO.
  • 1 protoboard.
  • 4 LEDs (rojo, verde, amarillo y azul).
  • 4 resistencias para LEDs.
  • 4 botones.
  • 1 buzzer.
  • Cables Dupont.
  • Computadora con Arduino IDE.

Descripción del funcionamiento

  • El juego muestra una secuencia de luces y sonidos.
  • El jugador debe presionar los botones en el mismo orden.
  • Si acierta, el juego agrega un nuevo color.
  • Si falla, el juego termina y muestra el nivel alcanzado.

Reglas del juego

  • Solo se puede presionar un botón a la vez.
  • El juego empieza seleccionando un nivel.
  • Cada color tiene su propio sonido.
  • El juego termina cuando la secuencia es incorrecta.

Organización del equipo

  • Programador: Carga y revisa el código.
  • Constructor: Realiza las conexiones.
  • Supervisor: Revisa que el juego funcione correctamente.

Reglas de seguridad

  • No conectar el Arduino sin revisar cables.
  • No tocar conexiones con el Arduino encendido.
  • Mantener orden en la mesa de trabajo.

Bloque 1 - Librería, pines y variables

#include <EEPROM.h>

#define altavoz A0

#define rojo 12
#define verde 11
#define amarillo 10
#define azul 9

#define botonrojo 7
#define botonverde 6
#define botonamarillo 5
#define botonazul 4

int aleatorio, dir_lectura, dir_escritura, color_leido, leido, color_pulsado, nivel;
boolean fin_juego;

En este bloque se define el mapeo exacto del diagrama: buzzer en A0, LEDs en 12, 11, 10 y 9, y botones en 7, 6, 5 y 4. También se declaran las variables que controlan la secuencia y el estado del juego.

Bloque 2 - Velocidad y sonidos

void retardo(int latencia) {
  latencia = nivel;
  switch (latencia) {
    case 1:
      delay(300);
      break;
    case 2:
      delay(200);
      break;
    case 3:
      delay(75);
      break;
    case 4:
      delay(5);
      break;
    default:
      break;
  }
}

void sonido(int tono) {
  int i, j;
  for (i = 0; i <= 40; i++) {
    for (j = 0; j <= 4; j++) {
      digitalWrite(altavoz, HIGH);
      delayMicroseconds(90 * (6 - tono));
      digitalWrite(altavoz, LOW);
      delayMicroseconds(90 * (6 - tono));
    }
  }
}

Estas funciones controlan la velocidad del juego según el nivel elegido y generan un tono distinto para cada color mediante pulsos en el buzzer.

Bloque 3 - Selección de nivel y antirrebote

void antirebote() {
  delay(30);
  while (digitalRead(botonrojo) != 1 || digitalRead(botonverde) != 1 || digitalRead(botonamarillo) != 1 || digitalRead(botonazul) != 1) {
  }
  delay(30);
}

void escoge_nivel() {
  int sale = 1;
  nivel = 1;
  digitalWrite(rojo, LOW);
  digitalWrite(verde, LOW);
  digitalWrite(amarillo, LOW);
  digitalWrite(azul, LOW);

  delay(100);
  aleatorio = 1;

  while (sale == 1) {
    genera_aleatorio();

    if (digitalRead(botonrojo) == LOW) {
      nivel = 1;
      digitalWrite(rojo, HIGH);
      sonido(nivel);
      sale = 0;
      antirebote();
    }

    if (digitalRead(botonverde) == LOW) {
      nivel = 2;
      digitalWrite(verde, HIGH);
      sonido(nivel);
      sale = 0;
      antirebote();
    }

    if (digitalRead(botonamarillo) == LOW) {
      nivel = 3;
      digitalWrite(amarillo, HIGH);
      sonido(nivel);
      sale = 0;
      antirebote();
    }

    if (digitalRead(botonazul) == LOW) {
      nivel = 4;
      digitalWrite(azul, HIGH);
      sonido(nivel);
      sale = 0;
      antirebote();
    }
  }
}

Aquí el jugador selecciona el nivel usando uno de los cuatro botones. El color elegido determina la dificultad y la función antirebote() evita lecturas falsas por rebote mecánico.

Bloque 4 - Memoria de la secuencia

void genera_aleatorio() {

  if (leido != color_pulsado) {

La secuencia del juego se va guardando en la memoria EEPROM. Después, cada pulsación del jugador se compara contra el color esperado para saber si sigue en juego o si falló.

Bloque 5 - Mostrar colores y leer pulsaciones

void enciende_led(int color) {
  switch (color) {
    case 1: digitalWrite(rojo, HIGH); break;
    case 2: digitalWrite(verde, HIGH); break;
    case 3: digitalWrite(amarillo, HIGH); break;
    case 4: digitalWrite(azul, HIGH); break;
    default:
      digitalWrite(rojo, HIGH);
      digitalWrite(verde, HIGH);
      digitalWrite(amarillo, HIGH);
      digitalWrite(azul, HIGH);
      break;
  }
}

void muestra_colores() {
  digitalWrite(rojo, LOW);
  digitalWrite(verde, LOW);
  digitalWrite(amarillo, LOW);
  digitalWrite(azul, LOW);
  retardo(nivel);

  for (dir_lectura = 0; dir_lectura < dir_escritura; dir_lectura++) {
    color_leido = EEPROM.read(dir_lectura);
    enciende_led(color_leido);
    sonido(color_leido);
    retardo(nivel);
    digitalWrite(rojo, LOW);
    digitalWrite(verde, LOW);
    digitalWrite(amarillo, LOW);
    digitalWrite(azul, LOW);
    retardo(nivel);
  }
}

Arduino recorre la secuencia guardada en EEPROM, enciende el LED correspondiente y reproduce su sonido. Así muestra al jugador el patrón que debe repetir.

Bloque 6 - Turno del jugador y fallo

        color_pulsado = 2;
        sal = true;
      } else if (digitalRead(botonamarillo) == 0) {
        color_pulsado = 3;
        sal = true;
      } else if (digitalRead(botonazul) == 0) {
        color_pulsado = 4;
        sal = true;
      }

En este bloque se esperan las pulsaciones del usuario, se comparan con la secuencia correcta y se activa el fin del juego si alguna entrada no coincide.

Código completo

#include <EEPROM.h>

#define altavoz A0

#define rojo 12
#define verde 11
#define amarillo 10
#define azul 9

#define botonrojo 7
#define botonverde 6
#define botonamarillo 5
#define botonazul 4

int aleatorio, dir_lectura, dir_escritura, color_leido, leido, color_pulsado, nivel;
boolean fin_juego;


void retardo(int latencia) {
  latencia = nivel;
  switch (latencia) {
    case 1:
      delay(300);
      break;
    case 2:
      delay(200);
      break;
    case 3:
      delay(75);
      break;
    case 4:
      delay(5);
      break;
    default:
      break;
  }
}

void sonido(int tono) {
  int i, j;
  for (i = 0; i <= 40; i++) {
    for (j = 0; j <= 4; j++) {
      digitalWrite(altavoz, HIGH);
      delayMicroseconds(90 * (6 - tono));
      digitalWrite(altavoz, LOW);
      delayMicroseconds(90 * (6 - tono));
    }
  }
}

void muestra_nivel(int pulsos) {
  int valor = (pulsos / 4);
  int resto = (pulsos % 4);
  for (int k = 1; k <= valor; k++) {
    digitalWrite(rojo, HIGH);
    digitalWrite(verde, HIGH);
    digitalWrite(amarillo, HIGH);
    digitalWrite(azul, HIGH);
    delay(800);
    digitalWrite(rojo, LOW);
    digitalWrite(verde, LOW);
    digitalWrite(amarillo, LOW);
    digitalWrite(azul, LOW);
    delay(800);
  }
  switch (resto) {
    case 1:
      digitalWrite(rojo, HIGH);
      break;
    case 2:
      digitalWrite(rojo, HIGH);
      digitalWrite(verde, HIGH);
      break;
    case 3:
      digitalWrite(rojo, HIGH);
      digitalWrite(verde, HIGH);
      digitalWrite(amarillo, HIGH);
      break;
  }
  delay(800);
  digitalWrite(rojo, LOW);
  digitalWrite(verde, LOW);
  digitalWrite(amarillo, LOW);
  digitalWrite(azul, LOW);
}

void antirebote() {
  delay(30);
  while (digitalRead(botonrojo) != 1 || digitalRead(botonverde) != 1 || digitalRead(botonamarillo) != 1 || digitalRead(botonazul) != 1) {
  }
  delay(30);
}

void comprueba() {
  leido = EEPROM.read(dir_lectura);
  if (leido != color_pulsado) {

void enciende_led(int color) {
  switch (color) {
    case 1: digitalWrite(rojo, HIGH);
      break;
    case 2: digitalWrite(verde, HIGH);
      break;
    case 3: digitalWrite(amarillo, HIGH);
      break;
    case 4: digitalWrite(azul, HIGH);
      break;
    default: digitalWrite(rojo, HIGH); digitalWrite(verde, HIGH);
      digitalWrite(amarillo, HIGH); digitalWrite(azul, HIGH);
      break;
  }
}

void genera_aleatorio() {
  if (aleatorio == 4) {
    aleatorio = 1;
  }
  else {
    aleatorio++;
  }
}

void guarda_color() {
  EEPROM.write(dir_escritura, aleatorio);
  dir_escritura++;
}

void escoge_nivel() {
  int sale = 1;
  nivel = 1;
  digitalWrite(rojo, LOW);
  digitalWrite(verde, LOW);
  digitalWrite(amarillo, LOW);
  digitalWrite(azul, LOW);

  delay(100);
  aleatorio = 1;

  while (sale == 1) {
    genera_aleatorio();

    if (digitalRead(botonrojo) == LOW) {
      nivel = 1;
      digitalWrite(rojo, HIGH);
      sonido(nivel);
      sale = 0;
      antirebote();
    }

    if (digitalRead(botonverde) == LOW) {
      nivel = 2;
      digitalWrite(verde, HIGH);
      sonido(nivel);
      sale = 0;
      antirebote();
    }

    if (digitalRead(botonamarillo) == LOW) {
      nivel = 3;
      digitalWrite(amarillo, HIGH);
      sonido(nivel);
      sale = 0;
      antirebote();
    }

    if (digitalRead(botonazul) == LOW) {
      nivel = 4;
      digitalWrite(azul, HIGH);
      sonido(nivel);
      sale = 0;
      antirebote();
    }
  }
  digitalWrite(rojo, HIGH);
  digitalWrite(verde, HIGH);
  digitalWrite(amarillo, HIGH);
  digitalWrite(azul, HIGH);
  delay(1000);
  digitalWrite(rojo, LOW);
  digitalWrite(verde, LOW);
  digitalWrite(amarillo, LOW);
  digitalWrite(azul, LOW);
  delay(500);
}

void has_fallado(int tono) {
  int i, j;
  enciende_led(color_pulsado);
  for (i = 0; i <= 100; i++)  {
    for (j = 0; j <= 4; j++) {
      digitalWrite(altavoz, HIGH);
      delay(1 * (6 - tono));
      digitalWrite(altavoz, LOW);
      delay(1 * (6 - tono));
    }
  }
  digitalWrite(rojo, LOW);
  digitalWrite(verde, LOW);
  digitalWrite(amarillo, LOW);
  digitalWrite(azul, LOW);

  delay(1000);
}

void muestra_colores() {
  digitalWrite(rojo, LOW);
  digitalWrite(verde, LOW);
  digitalWrite(amarillo, LOW);
  digitalWrite(azul, LOW);
  retardo(nivel);
  for (dir_lectura = 0; dir_lectura < dir_escritura; dir_lectura++) {
    color_leido = EEPROM.read(dir_lectura);
    enciende_led(color_leido);
    sonido(color_leido);
    retardo(nivel);
    digitalWrite(rojo, LOW);
    digitalWrite(verde, LOW);
    digitalWrite(amarillo, LOW);
    digitalWrite(azul, LOW);
    retardo(nivel);
  }
}

void pulsa_secuencia() {
  boolean sal;
  dir_lectura = 0;
  aleatorio = 1;
  while ((dir_lectura < dir_escritura) && (!fin_juego)) {

    sal = false;
    while (!sal) {
      genera_aleatorio();
      if (digitalRead(botonrojo) == 0) {
        color_pulsado = 1;
        sal = true;
      }
      else if (digitalRead(botonverde) == 0) {
        color_pulsado = 2;
        sal = true;
      } else if (digitalRead(botonamarillo) == 0) {
        color_pulsado = 3;
        sal = true;
      } else if (digitalRead(botonazul) == 0) {
        color_pulsado = 4;
        sal = true;
      }
      else {
        sal = false;
      }
    }
    comprueba();
    enciende_led(color_pulsado);
    sonido(color_pulsado);
    antirebote();
    digitalWrite(rojo, LOW);
    digitalWrite(verde, LOW);
    digitalWrite(amarillo, LOW);
    digitalWrite(azul, LOW);
    dir_lectura++;
  }
}

void setup()  {
  pinMode(botonrojo,  INPUT_PULLUP);
  pinMode(botonverde, INPUT_PULLUP);
  pinMode(botonamarillo, INPUT_PULLUP);
  pinMode(botonazul, INPUT_PULLUP);

  pinMode(rojo, OUTPUT);
  pinMode(verde, OUTPUT);
  pinMode(amarillo, OUTPUT);
  pinMode(azul, OUTPUT);
  pinMode(altavoz, OUTPUT);

  digitalWrite(rojo, LOW);
  digitalWrite(verde, LOW);
  digitalWrite(amarillo, LOW);
  digitalWrite(azul, LOW);
}

void loop() {
  for (int i = 0; i < 3; i++) {
    digitalWrite(rojo, LOW);
    sonido(1);
    digitalWrite(azul, HIGH);
    delay(100);
    digitalWrite(azul, LOW);
    sonido(2);
    digitalWrite(amarillo, HIGH);
    delay(100);
    digitalWrite(verde, HIGH);
    digitalWrite(amarillo, LOW);
    sonido(3);
    delay(100);
    digitalWrite(verde, LOW);
    sonido(4);
    digitalWrite(rojo, HIGH);
    delay(100);
  }
  dir_escritura = dir_lectura = color_leido = leido = color_pulsado = 0;
  fin_juego = false;
  aleatorio = 1;
  escoge_nivel();
  guarda_color();
  while (!fin_juego) {
    muestra_colores();
    pulsa_secuencia();
    guarda_color();
    if (!fin_juego) {
      enciende_led(5);
      sonido(1);
      sonido(2);
      sonido(4);
      delay(100);
      retardo(nivel);
    }
  }
  has_fallado(4);
  muestra_nivel(dir_escritura - 1);
  delay(300);
}

Explicación general del juego

  • El jugador selecciona la dificultad con uno de los cuatro botones.
  • Arduino guarda la secuencia de colores en memoria EEPROM.
  • El sistema muestra la secuencia con LEDs y sonidos.
  • El jugador intenta repetirla con los botones en el mismo orden.
  • Si falla, suena la alerta y se muestra el nivel alcanzado con los LEDs.
