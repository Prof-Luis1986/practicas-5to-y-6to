¿Qué vamos a aprender?

En este proyecto aprenderás a crear un juego de memoria usando una tarjeta Arduino, botones, luces y sonidos.

El reto será recordar una secuencia de colores que el sistema te mostrará y repetirla correctamente.

Aprendizajes esperados

  • Reconocer entradas (botones) y salidas (luces y sonido).
  • Seguir instrucciones paso a paso.
  • Comprender qué es una secuencia.
  • Relacionar acciones físicas con instrucciones digitales.
  • Trabajar en equipo y resolver problemas.

Materiales

  • 1 Arduino UNO.
  • 1 protoboard.
  • 4 LEDs (rojo, verde, amarillo y azul).
  • 4 resistencias para LEDs.
  • 4 botones.
  • 1 buzzer.
  • Cables Dupont.
  • Computadora con Arduino IDE.

Descripción del funcionamiento

  • El juego muestra una secuencia de luces y sonidos.
  • El jugador debe presionar los botones en el mismo orden.
  • Si acierta, el juego agrega un nuevo color.
  • Si falla, el juego termina y muestra el nivel alcanzado.

Reglas del juego

  • Solo se puede presionar un botón a la vez.
  • El juego empieza seleccionando un nivel.
  • Cada color tiene su propio sonido.
  • El juego termina cuando la secuencia es incorrecta.

Organización del equipo

  • Programador: Carga y revisa el código.
  • Constructor: Realiza las conexiones.
  • Supervisor: Revisa que el juego funcione correctamente.

Reglas de seguridad

  • No conectar el Arduino sin revisar cables.
  • No tocar conexiones con el Arduino encendido.
  • Mantener orden en la mesa de trabajo.

Código explicado por partes

Bloque 1 - Pines y sonidos

const int leds[4] = {2, 3, 4, 5};
const int botones[4] = {6, 7, 8, 9};
const int tonos[4] = {262, 330, 392, 523};
const int buzzer = 10;

En este bloque se definen los 4 LEDs, los 4 botones, los sonidos de cada color y el pin donde se conecta el buzzer.

Bloque 2 - Variables del juego

const int MAX_RONDAS = 20;
int secuencia[MAX_RONDAS];
int nivelActual = 1;

Aquí se guarda la secuencia del juego y se define cuántas rondas máximas se podrán jugar.

Bloque 3 - Configuración inicial

void setup() {
  for (int i = 0; i < 4; i++) {
    pinMode(leds[i], OUTPUT);
    pinMode(botones[i], INPUT_PULLUP);
  }

  pinMode(buzzer, OUTPUT);
  randomSeed(analogRead(A0));
}

Arduino prepara los pines, configura los botones como entrada y genera una semilla aleatoria para que la secuencia cambie en cada partida.

Bloque 4 - Mostrar la secuencia

void mostrarSecuencia(int nivel) {
  for (int i = 0; i < nivel; i++) {
    int color = secuencia[i];
    digitalWrite(leds[color], HIGH);
    tone(buzzer, tonos[color], 350);
    delay(450);
    digitalWrite(leds[color], LOW);
    delay(180);
  }
}

Esta función prende cada LED en orden y activa su sonido para que el jugador observe la secuencia que deberá repetir.

Bloque 5 - Lectura del jugador

int leerBoton() {
  while (true) {
    for (int i = 0; i < 4; i++) {
      if (digitalRead(botones[i]) == LOW) {
        digitalWrite(leds[i], HIGH);
        tone(buzzer, tonos[i], 200);
        delay(250);
        digitalWrite(leds[i], LOW);

        while (digitalRead(botones[i]) == LOW) {
        }

        delay(120);
        return i;
      }
    }
  }
}

Arduino espera a que el jugador presione un botón. Cuando detecta uno, enciende su LED, reproduce su sonido y regresa el número del color seleccionado.

Bloque 6 - Validación y avance de nivel

bool turnoJugador(int nivel) {
  for (int i = 0; i < nivel; i++) {
    int respuesta = leerBoton();

    if (respuesta != secuencia[i]) {
      return false;
    }
  }

  return true;
}

En este bloque el programa compara cada botón presionado con la secuencia correcta. Si hay un error, el juego termina.

Código completo

const int leds[4] = {2, 3, 4, 5};
const int botones[4] = {6, 7, 8, 9};
const int tonos[4] = {262, 330, 392, 523};
const int buzzer = 10;

const int MAX_RONDAS = 20;
int secuencia[MAX_RONDAS];
int nivelActual = 1;

void encenderTodos(int tiempo) {
  for (int i = 0; i < 4; i++) {
    digitalWrite(leds[i], HIGH);
  }

  tone(buzzer, 700, tiempo);
  delay(tiempo);

  for (int i = 0; i < 4; i++) {
    digitalWrite(leds[i], LOW);
  }
}

void mostrarSecuencia(int nivel) {
  for (int i = 0; i < nivel; i++) {
    int color = secuencia[i];
    digitalWrite(leds[color], HIGH);
    tone(buzzer, tonos[color], 350);
    delay(450);
    digitalWrite(leds[color], LOW);
    delay(180);
  }
}

int leerBoton() {
  while (true) {
    for (int i = 0; i < 4; i++) {
      if (digitalRead(botones[i]) == LOW) {
        digitalWrite(leds[i], HIGH);
        tone(buzzer, tonos[i], 200);
        delay(250);
        digitalWrite(leds[i], LOW);

        while (digitalRead(botones[i]) == LOW) {
        }

        delay(120);
        return i;
      }
    }
  }
}

bool turnoJugador(int nivel) {
  for (int i = 0; i < nivel; i++) {
    int respuesta = leerBoton();

    if (respuesta != secuencia[i]) {
      return false;
    }
  }

  return true;
}

void juegoPerdido() {
  for (int i = 0; i < 3; i++) {
    encenderTodos(180);
    delay(120);
  }
}

void iniciarJuego() {
  for (int i = 0; i < MAX_RONDAS; i++) {
    secuencia[i] = random(0, 4);
  }

  nivelActual = 1;
}

void setup() {
  for (int i = 0; i < 4; i++) {
    pinMode(leds[i], OUTPUT);
    pinMode(botones[i], INPUT_PULLUP);
  }

  pinMode(buzzer, OUTPUT);
  randomSeed(analogRead(A0));
  iniciarJuego();
}

void loop() {
  mostrarSecuencia(nivelActual);

  if (turnoJugador(nivelActual)) {
    tone(buzzer, 900, 250);
    delay(350);
    nivelActual++;

    if (nivelActual > MAX_RONDAS) {
      nivelActual = MAX_RONDAS;
      encenderTodos(800);
      iniciarJuego();
    }
  } else {
    juegoPerdido();
    iniciarJuego();
    delay(600);
  }

  delay(400);
}

Explicación general del juego

  • Arduino genera una secuencia aleatoria de colores.
  • El sistema muestra la secuencia con LEDs y sonidos.
  • El jugador intenta repetirla con los botones.
  • Si responde bien, avanza al siguiente nivel.
  • Si se equivoca, el juego reinicia.
