Cabeza dinosaurio

Dos mecanismos de ojo y párpado animados con servomotores para simular mirada lateral y parpadeos en una cabeza de dinosaurio.

Volver al índice

Guía de trabajo

Título de la práctica: Cabeza dinosaurio

Modalidad: Individual o por equipos

Duración estimada: 4 a 6 sesiones

Ajusta los ángulos de apertura y cierre según el mecanismo físico antes de presentar el proyecto.

Producto final identificado

Programar dos mecanismos de ojo y párpado para una cabeza de dinosaurio. Cada modelo usa dos servomotores: uno mueve el ojo hacia izquierda, centro y derecha, y otro abre y cierra el párpado para simular parpadeos.

Prototipos de práctica antes del modelo final

Las piezas de la máscara y del ojo que aparecen en esta sección son prototipos iniciales. No representan el acabado final del dinosaurio: se usarán para practicar armado, ajuste, pintura y corrección de errores antes de trabajar con las piezas definitivas.

El objetivo es aprender con estas pruebas sin perder de vista el modelo final. Si una pieza queda chueca, roza, se pinta de forma irregular o no permite cerrar bien el ojo, no se considera un fracaso; se registra como una mejora que deberá aplicarse cuando llegue la versión final.

El video se muestra sin sonido para que se use como referencia visual del movimiento del prototipo.

Qué deben practicar con estos prototipos

  • Identificar dónde se colocarán los servos y qué partes podrían estorbar el movimiento.
  • Ensayar lijado, unión de piezas, refuerzos y pintura sin arriesgar el modelo final.
  • Probar ángulos pequeños antes de usar movimientos amplios en el mecanismo de ojos.
  • Anotar errores visibles y decidir qué se corregirá en la versión final.

Preguntas para documentar las pruebas

Contesta estas preguntas después de manipular los prototipos. Las respuestas servirán como guía para no repetir los mismos errores cuando se arme la cabeza definitiva.

Evidencia mínima de esta etapa

  • Foto de la máscara y el ojo antes de hacer ajustes.
  • Foto o video corto de una prueba de movimiento del ojo.
  • Lista de al menos tres mejoras que se aplicarán al modelo final.
  • Registro de los ángulos seguros encontrados para mover ojos y párpados.

Importante: estas imágenes sirven como referencia de prueba. La entrega final debe mantener la idea de una cabeza de dinosaurio expresiva, con dos modelos de ojo y párpado que miran hacia los lados y parpadean sin atorarse.

Objetivo 1: Investigar cómo ocurre un parpadeo natural

Descripción: Observar durante un tiempo breve cómo parpadean las personas o un personaje animado. Identificar cuánto dura el cierre del párpado y cómo cambia la mirada antes o después del parpadeo.

Entrega: Registro de cinco parpadeos observados y tres conclusiones sobre duración, pausa y posición de la mirada.

Evaluación: Las conclusiones reconocen que el cierre es breve, la mirada puede moverse entre parpadeos y las pausas pueden variar.

Objetivo 2: Planear los movimientos del ojo y el párpado

Descripción: Definir los estados mirar izquierda, mirar centro, mirar derecha, párpado abierto y párpado cerrado. Ordenar en una línea de tiempo las posiciones y pausas necesarias.

Entrega: Secuencia ilustrada de cada estado con posiciones y tiempos aproximados.

Evaluación: La secuencia distingue movimiento de mirada y movimiento de párpado, y puede repetirse en dos modelos con dos servos cada uno.

Objetivo 3: Diseñar el mecanismo de ojo y párpado

Descripción: Revisar el diagrama, identificar el servo del ojo y el servo del párpado de cada modelo, y crear un boceto que muestre cómo cada servo moverá su pieza sin chocar con la estructura.

Entrega: Diagrama etiquetado y boceto frontal del mecanismo con el sentido de movimiento de cada servo.

Evaluación: Cada servo está asociado con la pieza correcta y el diseño deja espacio para mirar y parpadear sin forzar el mecanismo.

Objetivo 4: Calibrar cada servo por separado

Descripción: Conectar un servo a la vez y probar ángulos pequeños hasta encontrar posiciones seguras para izquierda, centro, derecha, párpado abierto y párpado cerrado.

Entrega: Tabla con los ángulos seguros del ojo y del párpado.

Evaluación: Los valores fueron probados, no fuerzan el mecanismo y permiten distinguir claramente mirada y parpadeo.

Objetivo 5: Programar mirada y parpadeo

Descripción: Coordinar el servo del ojo con el servo del párpado en cada modelo. Probar diferentes duraciones hasta que el movimiento se vea claro y los párpados cierren sin golpear.

Entrega: Video de tres ciclos completos y registro de la duración de cierre elegida.

Evaluación: Los ojos se mueven a izquierda, centro y derecha; los párpados abren y cierran; y los cuatro servos regresan a posiciones seguras.

Objetivo 6: Integrar el movimiento en la máscara

Descripción: Colocar los dos modelos de ojo y párpado dentro de la máscara. Probar si cada pieza mira a los lados y parpadea sin rozar, atorarse o perder fuerza.

Entrega: Video comparativo con una prueba fuera de la máscara y una prueba dentro de la máscara.

Evaluación: Las dos pruebas son visibles, el mecanismo conserva su recorrido y termina en una posición correcta.

Objetivo 7: Mejorar sincronización y montaje

Descripción: Observar roces, piezas flojas o movimientos invertidos y ajustar ángulos o tiempos sin cambiar las funciones principales del proyecto.

Entrega: Lista de ajustes realizados y prueba continua de al menos cinco ciclos de mirada y parpadeo.

Evaluación: Los mecanismos no se atoran, los servos no se fuerzan y ambos modelos conservan movimientos repetibles.

Materiales

  • 1 Arduino Uno
  • 4 servomotores SG90 o similares
  • 2 mecanismos de ojo y párpado
  • Fuente externa regulada de 5 V para los servos
  • Protoboard
  • Cables Dupont
  • 1 cable USB

Descripción general

La práctica controla cuatro servos en total. Cada modelo tiene un servo para mover el ojo hacia los lados y otro servo para mover el párpado. El programa hace que ambos modelos miren a la izquierda, parpadeen, regresen al centro, miren a la derecha y vuelvan a parpadear.

Explicación del funcionamiento

El programa usa la librería Servo para enviar ángulos a cada mecanismo. En el modelo 1, el ojo usa el pin 6 y el párpado usa el pin 9. En el modelo 2, el ojo usa el pin 10 y el párpado usa el pin 11. Los valores de ángulo definen centro, izquierda, derecha, párpado abierto y párpado cerrado.

Códigos de prueba para ojos

Estos códigos sirven para probar el movimiento lateral antes de usar el modelo final con párpado. Primero prueba un solo ojo y después prueba dos ojos si el prototipo tendrá dos mecanismos sincronizados.

Prueba 1: Un solo ojo

Conecta el servo del ojo al pin 9. El ojo irá a la izquierda, regresará al centro, irá a la derecha y volverá al centro.

Componente Cable Arduino Uno
Servo SG90 Señal (naranja) D9
Servo SG90 VCC (rojo) 5V
Servo SG90 GND (café/negro) GND 
#include <Servo.h>

Servo ojo;

const int CENTRO = 90;
const int IZQUIERDA = 75;
const int DERECHA = 105;

void setup() {
  ojo.attach(9);
  ojo.write(CENTRO);
  delay(1000);
}

void loop() {

  // Mira a la izquierda
  ojo.write(IZQUIERDA);
  delay(800);

  // Centro
  ojo.write(CENTRO);
  delay(500);

  // Mira a la derecha
  ojo.write(DERECHA);
  delay(800);

  // Centro
  ojo.write(CENTRO);
  delay(1200);

}

Prueba 2: Dos ojos

Conecta el servo del ojo izquierdo al pin 9 y el servo del ojo derecho al pin 10. Los dos ojos se moverán al mismo lado y regresarán al centro.

Componente Cable Arduino Uno
Ojo izquierdo Señal D9
Ojo izquierdo VCC 5V
Ojo izquierdo GND GND
Ojo derecho Señal D10
Ojo derecho VCC 5V
Ojo derecho GND GND 
#include <Servo.h>

Servo ojoIzq;
Servo ojoDer;

void setup() {

  ojoIzq.attach(9);
  ojoDer.attach(10);

  ojoIzq.write(90);
  ojoDer.write(90);

  delay(1000);
}

void loop() {

  // Miran a la izquierda
  ojoIzq.write(75);
  ojoDer.write(77);
  delay(800);

  // Centro
  ojoIzq.write(90);
  ojoDer.write(90);
  delay(500);

  // Miran a la derecha
  ojoIzq.write(105);
  ojoDer.write(103);
  delay(800);

  // Centro
  ojoIzq.write(90);
  ojoDer.write(90);
  delay(1200);

}

Código completo

Este es el código final para dos modelos. Cada modelo tiene un servo que mueve el ojo y un servo que mueve el párpado.

#include <Servo.h>

Servo ojoModelo1;
Servo parpadoModelo1;
Servo ojoModelo2;
Servo parpadoModelo2;

const int CENTRO_OJO = 90;
const int IZQUIERDA = 70;
const int DERECHA = 110;

const int PARPADO1_ABIERTO = 90;
const int PARPADO1_CERRADO = 35;

const int PARPADO2_ABIERTO = 90;
const int PARPADO2_CERRADO = 35;

void setup() {
  ojoModelo1.attach(6);       // Ojo del modelo 1
  parpadoModelo1.attach(9);   // Párpado del modelo 1
  ojoModelo2.attach(10);      // Ojo del modelo 2
  parpadoModelo2.attach(11);  // Párpado del modelo 2

  ojoModelo1.write(CENTRO_OJO);
  parpadoModelo1.write(PARPADO1_ABIERTO);
  ojoModelo2.write(CENTRO_OJO);
  parpadoModelo2.write(PARPADO2_ABIERTO);

  delay(1000);
}

void loop() {

  // Miran a la izquierda
  ojoModelo1.write(IZQUIERDA);
  ojoModelo2.write(IZQUIERDA);
  delay(700);

  // Parpadeo de los dos modelos
  parpadoModelo1.write(PARPADO1_CERRADO);
  parpadoModelo2.write(PARPADO2_CERRADO);
  delay(180);
  parpadoModelo1.write(PARPADO1_ABIERTO);
  parpadoModelo2.write(PARPADO2_ABIERTO);
  delay(500);

  // Miran al centro
  ojoModelo1.write(CENTRO_OJO);
  ojoModelo2.write(CENTRO_OJO);
  delay(500);

  // Miran a la derecha
  ojoModelo1.write(DERECHA);
  ojoModelo2.write(DERECHA);
  delay(700);

  // Parpadeo de los dos modelos
  parpadoModelo1.write(PARPADO1_CERRADO);
  parpadoModelo2.write(PARPADO2_CERRADO);
  delay(180);
  parpadoModelo1.write(PARPADO1_ABIERTO);
  parpadoModelo2.write(PARPADO2_ABIERTO);
  delay(1000);

}

Si un párpado se mueve al revés, invierte solo los valores de ese modelo. Por ejemplo: const int PARPADO1_ABIERTO = 35; y const int PARPADO1_CERRADO = 90;. Haz este cambio solo después de probar los mecanismos lentamente.

Producto final

Descripción: Dos mecanismos de ojo y párpado con cuatro servomotores en total: cada modelo controla la mirada lateral y realiza el parpadeo en una cabeza de dinosaurio.

Entrega:
