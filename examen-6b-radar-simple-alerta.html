Instrucciones

Utilizando Tinkercad Circuits, construye la simulación de un radar simple con alerta.

El sistema deberá detectar objetos utilizando un sensor ultrasónico. Cuando un objeto se encuentre cerca, se deberá activar una alerta visual y sonora.

Analiza el código proporcionado, completa los espacios faltantes y realiza el diseño del circuito para que funcione correctamente.

Materiales

  • 1 Arduino Uno
  • 1 Protoboard
  • 1 Sensor ultrasónico HC-SR04
  • 1 LED rojo
  • 1 LED verde
  • 2 resistencias
  • 1 Buzzer
  • Cables de conexión

const int TRIG = 9;
const int ECHO = 10;

const int LED_ROJO = 3;
const int LED_VERDE = 4;

const int BUZZER = 8;

const int DISTANCIA_ALERTA = 30;

long medirDistancia() {

  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);

  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);

  long duracion = pulseIn(ECHO, HIGH, 30000);

  if (duracion == 0) return -1;

  long distancia = duracion / 58;

  return distancia;
}
